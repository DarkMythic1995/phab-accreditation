# PHAB Accreditation Data Pipeline
Simulates the organization and validation of public health data for PHAB accreditation, inspired by my internship at Waushara County Health Department.  
- **Tools**: Python, Pandas  
- **Features**: Data cleaning, validation, and structuring into a PHAB-compliant CSV.  
- **Run**: `python phab_accreditation_pipeline.py`
